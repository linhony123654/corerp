## Execution contract

1. Concept: a continuing life read as a paper-and-ink notebook, with personal objects opened only when needed.
2. Protagonist: current scene and spoken narrative; while a wallet is open, its actual balance is the single focal fact.
3. Supporting layers: date/place annotations, rust-colored chapter seal, quiet paper grain; optional personal-object entry beside scene actions.
4. Typography: existing CJK serif for scene/story and wallet amount; existing sans for actionable labels, tabular numerals for exact money. Preserve readable 17–18px prose and generous line spacing.
5. Material: warm paper with thin ink rules, not a card grid. Wallet is one semantically distinct folded sheet.
6. Color: existing paper #f1eee5 / ink #343d35 / rust #7e4935; dark green primary actions. Backdrop dims but does not replace the current place.
7. Motif: chapter seal and small “随身” marginal heading; no invented bank brand, card number, transaction or currency.
8. Composition: narrow reading column; one on-demand wallet sheet, amount above a ruled timestamp/footer. No dashboard metrics or technical cursor IDs on screen.
9. Motion: quiet / immediate / stable. No continuous animation, artificial typing or delayed balances; preserve scroll and restore opener focus. Native modal focus containment and Escape.
10. Density: restrained reading field with detail at chapter and object boundaries; wallet includes ownership, currency, snapshot time, refresh and honest empty/error/loading states.
11. Responsive: centered sheet on desktop; bottom-aligned sheet on phone with safe-area spacing, bounded height and internal overflow. Amount wraps safely; 44px controls; identity stays paper-and-ink.

## Increment gate

Wallet entry is disabled during pending world actions. Loading/error use their own state, never the world-action retry bookmark; retry only repeats the read. Close during a request must not update a later dialog. Each opening reads fresh server data. Currency formatting uses exact integer strings and server scale, never Number(amount)/100. Zero is an actual balance, not an empty placeholder. Snapshot metadata remains separate from the world's action cursor.

Required evidence: real-service browser read matching SQLite, error/retry, close/reopen, keyboard focus/Escape, 390px and desktop rendered review, no horizontal overflow or credential persistence; existing world-action lost-response/restart regression remains required. This contract does not establish completion of settings, work, contacts, messages, map, streaming or100+turn acceptance.
