## Boundaries that must remain in the final report

- Live external model quality is REQUIRED_IF_AVAILABLE / NOT VERIFIED in the
  earlier reports because no task-scoped endpoint/model/key was configured.
  Local HTTP fixtures and deterministic Final do not establish remote prose quality.
- Earlier stage deferrals to later stages are historical sequencing, not current
  outstanding features or permission to omit a Final requirement. The final
  deferred list must contain only original out-of-goal advanced systems.
- Recruitment actors in Final submit explicit authorized commands; the scenario
  does not claim that all career/culture/law actions were spontaneously chosen
  by an LLM. Existing optional local organization decisions are labeled as such.
- RP4 executable gift norms and speech prohibitions are bounded mechanisms, not
  arbitrary prose-interpreted law or a genealogy simulator. RP8 packages are
  declarative, not arbitrary executable plugins or hot upgrades.
- RP8 initial creator UI is bounded; larger supported specs are API-only,
  player movement is instantaneous, and link-duration settings are not effective.
- No stage publishes, deploys or uses real external accounts. Older code must not
  open a newer world database blindly; preserve matching backups and source history.
