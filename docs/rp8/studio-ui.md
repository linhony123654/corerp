# Studio event-evidence UI

Implemented at explicit `/studio`; `/` still mounts real Play and `/demo` still
mounts the historical static presentation. No migration or new frontend package.
`StudioWorkspace.vue` consumes authenticated scope/timeline/event reads and delegates
explicit explanation reads to `StudioExplanation.vue`.
Grant/revoke remains the explicit [local administrator tool](access.md), not a UI
toggle or SQL editor. Current scope is an event-evidence slice, not all8A–C.

## Visual contract

Historical package inspection extends the existing numbered rule-evidence section,
not the page composition: labelled activation/algorithm/source metadata followed by
native collapsible package JSON. Reuse dark/amber/Plex, long-ID wrapping, current
focus styles and bounded raw-content scroll. Source navigation repeats normal
authorized event reads. No new imagery, animation, dependency or visual direction.
Keep installation evidence distinct from a claim that every installed rule caused
this event; preparation/legacy/operator states explicitly explain missing content.

An instrument for reading the world's recorded facts: actual Event sequence/type
is the protagonist, with branch/batch lineage, effective Rule Epoch and recorded
causation as supporting layers. Reuse CoreRP's dark ink, amber authority marks,
teal navigation and Plex body/mono hierarchy. A split operation/result composition
uses one evidence axis, not repeated dashboard cards. No imagery or animation is
needed for this reading task; no added media, font, icon or component dependency.
Mobile recomposes the scope fields in two columns while keeping the Event ID and
token full width, then presents a full-width evidence reading area; long raw data
is collapsible and bounded in height. Input focus, semantic labels, busy/error/empty
states and explicit authority levels remain visible without hover or color alone.

Reference research is recorded in findings.md: official Grafana inspect-view
and pgAdmin query-tool docs informed operation/result separation, not a copied
visual skin. The web-inspiration-toolkit review caught a real global `.rule`
class collision; renamed it `.studio-rule` and added measured non-overlap checks.

## Privacy and interaction

Tokens, query results and inputs remain in page memory, never local/session
storage, URL parameters or Play state. Same-origin fixed-route POST, header-only
bearer, no cookies/redirects/cache,20s timeout. Input changes clear the old result
and abort the old read synchronously; request revision checks reject late responses.
Pagehide/unmount, explicit clear, reload and return-to-Play clear credentials/results.
Browser-owned password-manager behavior is not controlled by application storage.

HTTP error messages are local allowlisted copy; raw upstream errors/JSON parse
exceptions are not displayed. Binding mismatch and operator responses containing
unredacted private fields are refused. Raw content is escaped text, not rendered
HTML or model instructions. A snapshot label makes explicit that repeated reads
recheck authorization; this is not a live revoke-push subscription.

Current entry supports [authorized discovery and timeline selection](discovery.md)
without typing instance/branch/Event IDs; manual exact references remain. No fabricated
world data, inferred NPC intent or claim that absent causation means no cause.

The explanation section extends the same numbered evidence axis, typography and
ink/amber palette; no new cards, images, animations or dependencies. It independently
requests `events/explain` only after an explicit click, with optional creator observer
lookup and separate diagnostic/observer pagination. Permission errors do not pretend
that ordinary event access includes explanation access. Labels distinguish candidate
validation from committed effects and missing observations from subjective ignorance.
Changing credentials, Event or observer clears results; unmount aborts and invalidates
late responses. Fixed-route requests and redaction/binding checks match event reads.
