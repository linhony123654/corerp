## 1. Golden 暴露的结构性失败

原冻结世界缺少关键 persona/关系信息，17 个 not-ready 结果是正确的数据缺失证据，原始配置与失败样本继续保留。本次在用户明确委托的内容编写权限下，另建完整的 READY 荣庆堂配置；并非让模型依据《红楼梦》自行补 canon。11 人、9 地点、10 通路保持原世界结构，明确声明 10 位 NPC persona、公开表达线索与玩家之间的关系/称呼。未声明 NPC 相互熟悉、共同过去、座椅姿态、天气或初始活动。

在修改本次运行时之前冻结 `product-golden-scenes-2026-10-01.json` 和编写后的世界。旧二进制 f236 的基线已经能认出熟人、使用祖孙称呼、拒绝读取远处角色内心、回应取消约定。这些不能归功于本次改造。它主要暴露：正文逐条时间戳/地点/“回应”包装；角色反复邀坐、安慰、微笑；对白会断言没有来源的姿态、习惯或过去。基线不是逐字输出目标。

## 2. Context Contract

沿用唯一 `BuildRPDecisionInput`，没有第二套世界或平行 context builder。既有 packet 继续承载作者 persona、方向性关系、称呼、可见人物与活动、实际听闻、获准知识、自己的行动、来源、head/readiness 与自己的私有决策。

本次选择策略升级为 v3：最新两个与当前对话者的完整、获准交换，在全局候选上限前保留；无需关键词相同，等待时也可取回。优先修补近期交换，再保留当前对话者交换，然后按话题选取；完整组和总预算仍受限。私有回忆先取当前对话者的最近一条，再与全局三条去重，最多四条，保留原时间与对话者。缺失、陌生、截断、过期决策都不能变为 canon。

## 3. NPC Decision Contract

保留上一增量已经实现的 v3 `private + observable` 单一契约、短 intent/emotion/relationship stance、合法动作分支、来源 handle 绑定和 typed owner 提交。本次重点使已获准的完整上下文与自己的历史决策能够进入真实决策，不另建人格状态库。

重要限制：`basis_event_ids` 验证“引用是获准且存在的”，不是证明每个对白陈述都被这些事件蕴含。NPC 可以说错、猜测或夸张；账本保存的是“说过这句话”，不会因此执行递茶、坐下、留灯或确认共同童年。这是当前功能准确度的主要剩余缺口，不能通过重新标注来源或 Narrator 改词消除。

## 4. Observable / private 边界

非言语动作沿既有 owner 先提交，确定见证与目标后才公开。只有真实 causation 链可把相邻对白/表情组成一组；共享 batch/time 本身不证明同时发生。私有 intent 不进入事件公开 payload、叙事输入或客户端。

078 additive migration 为正文/版本保存冻结的公开 input、有限 composition plan、hash，与独立有序 Event IDs/事实组并列。重读会从所属回合的历史 head 重建完整获准来源，检查全部事实字段、历史身份、公开 cue、activity label、见证和 causal linkage，再重展开并比对全文。自造内容后重新算普通 hash 不能代替世界验证。保存正文与 settled boundary/cursor 同事务，网络与流输出不占长事务。

## 5. Narrator 表现能力

默认正文现在使用 `fact-composition.v2`：自然段落、对白前后置、精确同义手势、可追认对白与动作的组合、一次场景定位、公开 cue 的角色局部措辞。去除每一事实重复 ISO 时间/地点的日志包装。可选真实模型也只能选择同一有限表达文法。

仍不允许任意自由正文、新动作/人物/物品、玩家同意或移动、未公开意图、虚构因果/同时性、改写对白/拒绝/目标或改变世界状态。它是表现层 renderer，尚不是完全自由的文学写作器。普通默认世界正文不增加第二次模型往返；显式 `FullProse=true` 世界保持一次模型精修策略，之后复用存稿。显式重生成产生独立保存版本；旧 v1 不伪装成 v2。

## 6. Hard rule / soft signal

Hard：not-ready 缺失必要数据、非法/重复来源、越出可见性与 actor scope、非法动作字段/目标、熟悉关系显式重复介绍、未提交 observable 进入叙事、来源缺失/重复/重排、对白或 committed fact 改写、私有数据混入公开 artifact、伪造历史输入/事实组。

Soft 或人工：答非所问、反复台词/手势、未经声明的过去经历或惯常特征、人格漂移、自然度、趣味性。现有 bounded reply diagnostic/重写只辅助质量；不把不可靠语义分类器设为绝对硬门。合法 source handle 不是语义 entailment gate。

## 9. 剩余问题与下一步

首要问题转为 NPC proposal 的语义准确度：区分作者事实、目击/听闻、对话陈述、旧私有意图与当前可执行行动；不要把合法引用当作整句准确，也不要让自己的未证实对白经回忆循环成为背景事实。更精细的出处语义和逐项 soft diagnostic 值得下一次有针对性的修改；自由对白不可能靠来源 ID 的存在性检查保证全部正确。

有限回忆不等于完整长期记忆；自己的私有历史不等于目标兑现系统；显式首次精修并发可能产生两个上游尝试，但两个调用者读取同一已保存胜出稿，后续读取零调用。未设定的共同过去/天气/姿态不能临时写入世界修复某句样本。模型仍有长尾延迟；当前数据只是一组同条件输出，不是可靠性统计。旧世界仍保留缺失声明，不会静默被样板 canon 覆盖。
