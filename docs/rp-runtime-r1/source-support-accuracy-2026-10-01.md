# R1 准确度增量：来源含义与叙述时间窗口

实现已完成，角色准确度仍未通过。此次实际修正两个问题：NPC 输入里的来源句柄缺少“能证明什么”的类型；新会话把另一会话的旧表情再次写入当前叙述。世界账本能保证角色确实说过一句话，不保证这句话中的经历、物品和姿态正确。

这仍属于 R1。没有新增世界、owner、插件、总结记忆或语义评分器；不再重新盲跑原 32 轮来判断对白是否改善。

## 上下文与决策

沿唯一 `BuildRPDecisionInput` 与既有选择/身份投影，在最终获准输入上编译 `core.RPDecisionEvidenceSupport`。既有 `grounding_sources.ref` 增加 `support_ranges`，同时声明 `corerp.evidence-support.v1`。同一 Event 可以对应多个字段，但每个字段的支持范围不互相扩展。目录保留定位、角色/对象、已提供的时点、完整性、状态与允许用途；不检索新信息、不复制私有文本、不替模型补 canon。

| 已提供的内容 | 能支持的用途 | 不能据此确认 |
|---|---|---|
| 作者 persona、关系与称谓 | 已声明的特征、角色关系、称谓 | 未声明共同过去与原著剧情 |
| 自己说过、亲耳听见 | 谁说过什么；完整文本可精确引用 | 话语命题为真、承诺已兑现 |
| 已记录的自己动作、可见活动 | 具体时点的动作与明确状态 | 姿态一直持续、未见结果 |
| 行程计划 | 已声明计划 | 已经完成行程 |
| 自己的旧 private | 原时点、原交流对象下的内部意图 | 当前永久目标、公开世界事实 |
| 仅祖先 ID 或未识别范围 | 来源关联 | 自动授权事实断言 |

NPC 回复仍是原 v3 `private + observable`，提交 owner 与许可、branch head、input hash、来源存在性和动作验证保持原样。范围目录不是对白蕴含证明：没有宣称自由文本每个命题都被硬验。引用合法、actor scope、可见性与有限动作仍是 hard rule；自然度、重复、人格漂移、自由对白内未设定的经历/姿态继续是 soft 或人工检查。未加入会漏标命题的 claim manifest 或额外模型往返。

## 旧动作重复展示的修复

真实公开烟测中，两次 API 对话的 session 与随后浏览器对话的 session 不同。`readRPNarrativeInputAtHead` 的旧窗口只取当前 session 的前次结算 head，非言语来源却按观察者实体取；另一 session 的配套对白被过滤，两次旧 smile 因而再次独立呈现。v2 去掉逐条时间戳后，读者会把它们当作新动作。原始 `product-preview-release-2026-10-01.json` 保留了该失败正文及确切 Event IDs。

079 为应用会话增加不可变 `opened_sequence`。仅新建会话在同一写事务中冻结 branch head；幂等重开、观察、恢复都不推进它。新的叙述窗口取 opening、章节与该 session 前次结算的最大边界。`Observe` 的跨 session 历史不使用 opening 过滤，因此没有借新篇清掉正确长对话；打开后确实发生的主动招呼/表情仍进入下一轮。旧会话迁移值为 0，不回填、重写旧正文或改动旧事实；手动旧 schema 沿原路径兼容。该字段不暴露于玩家会话 JSON，不是第二套世界状态。

原 Narrator 的有限 v2 表达能力没有继续扩权；它仍只能渲染提交后的公开 observable，不能补玩家坐下、椅子、天气或 private intent。

## 验证与实际输出

core/decision 的定向范围、四种传输与预算验证通过。真实 storage builder→身份/预算投影→范围目录的集成验证通过（9.936 秒）；会话、章边界、artifact、窗口与各 durable-stage 恢复集合通过（34.078 秒），另有见证/不可见边界集合（4.188 秒）与已有旧数据库升级用例通过。完整 HTTP 包通过（72.505 秒）。新二进制及所有生产源文件的逐文件 hash 见 [独立验证记录](source-support-verification-2026-10-01.json)。预算限制针对序列化 `decisionContext`，并非包含 system/tools 的整个 HTTP 请求体；不能把二者混称。

保留冻结作者设定、模型与参数，从原 Golden 选择 P2、P3、P6 共七条输入，两个独立数据库采用同一个脚本和 setup helpers。每组七次真实 Step 决策成功、七次 HTTP 尝试，重启守恒通过。没有重跑原 32 轮，也没有把此片段当作完整 22 轮复评。[七轮可检查对照](source-support-compare-2026-10-01.html)，[Before](source-support-before-2026-10-01.json)，[After](source-support-after-2026-10-01.json)。

这组新版未再补“方才念着你”，茶水描写减少；第五轮对“不急着劝我高兴”的回应更贴当前输入。但第七轮仍把“我还在原处，没有过去”说成“你站在那儿不动”，重复邀坐也仍在。NPC 说自己“只当你是害臊”属于公开表达自己的猜测，不应被当成玩家内心已成立。世界仍只记录这些话与真正提交的手势。

两组轮次耗时之和为 107.460 / 88.211 秒；单组随机生成的差异不构成准确率、性能或改动因果的统计证明。人工角色体验保持 PENDING，语义准确度 **未通过**。

## 发布与剩余出口

此增量已更新到同一个[隔离试玩预览](https://code.linhony.xyz:4188/)，[七轮对照](https://code.linhony.xyz:4188/rp-review/accuracy/)可直接查看。后端 runtime 为 `feea3b32f0315d95fa447e89d48f1bae3e991e690fe0b98e9f6d20bf18eb834d`，433 个生产源文件摘要为 `0200985bba147b36d7cdf6578b9276e88d87a44b55e54c44410942c7bc032ee6`。页面与模型配置未改，仍默认 Step 5 Preview；代码发布身份由预览的 `release.json` 独立记录。

真实预览库的隔离副本先完成 078→079 升级：198 条事件、各分支 head、provider 回执数量与旧 canonical 正文摘要守恒，四段已见历史保持一致。正式激活再次验证同样的守恒，24 个旧 session 均保留 opening=0。随后在既有 R1 世界新开 session，opening=28；四段共享历史仍可读，三条旧 expression 没有重播到当前正文。一次真实默认 Step 决策成功（8.205 秒），只提交两条 speech 与一个当前 smile，原三个世界的 head 不变。重启后公开正文、来源与 provider 回执原样读取，没有新增事件或调用。证据见[发布记录](source-support-preview-release-2026-10-01.json)。

这次真实正文仍出现“那便站着说也无妨”和“座儿总给你留着”。玩家只声明留在原处，作者场景未声明可用座位；旧对话中说过这些，并不能使它们变成当前世界事实。新会话时间窗口的 bug 已解决，NPC 的无依据说法仍未解决。Technical smoke PASS 与 speech semantics NOT PASSED 并列保留，不能用前者掩盖后者。

升级与烟测脚本的初次环境模式、历史比较及 nullable ID 假设失败保留在发布目录和记录中；这些发生在零实际模型调用的检查阶段，修正的是验证 harness，不是放宽产品权限或事实检查。079 发布前的一致性备份为 `/home/ubuntu/.local/share/corerp-preview/backups/20261001-source-support-079/`。

旧 e3/f5dd 版本的原 32 轮捕获与恢复后置证据独立保留，不能借它标记新二进制的完整 32 轮 PASS。新的完整 Golden 与人工体验尚未通过，因此不宣布 R1 DONE，不进入 R2/R3。

主要剩余缺口是自由对白对姿态、未提供的场景可交互内容与旧说法的推断。目录提高可检查性，没有机械封闭这些陈述。应继续针对真实失败改统一事实/可执行范围契约，保持正常疑问、愿望、比喻和猜测可用；不能临时补出座椅/童年 canon、清历史或拿普通语义分类器作绝对硬门。

079 的新会话正文依赖 opening 边界重构；降回不认识 079 的 reader 未经验证，不应在新增正文后用旧二进制回滚并假定兼容。既有 mutable chapter 边界可能影响历史重构是独立代码推断，尚未复现，本次不扩为全面 artifact 改造。

五个同默认模型审计任务还核对了一条原有 hard rule：声明关系要求明确 acquaintance pair，合法创建和重建路径都建立双方 familiarity，因此“单向关系导致身份泄露”的怀疑不成立。但 `known_relationship_introduction` 在熟人明确询名时仍硬拒绝报姓名，属于已核对的语义规则过宽。本次未改此第三处生产路径；它是后续 R1 需处理的边界问题，不能把移除一条词法限制宣称成整体角色体验已修复。
